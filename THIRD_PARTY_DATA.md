# Third-party and restricted-data boundary

## ERA5-Land

ERA5-Land remains subject to the applicable Copernicus license and source terms. This repository does not redistribute raw ERA5-Land NetCDF files or complete ERA5-derived grids. Users obtaining ERA5-Land independently are responsible for complying with the original Copernicus terms.

## Station and provider records

WeatherXM and other raw station records are not publicly distributed in this repository. The public code and aggregate summaries do not grant a license to any upstream provider data.

## Olympic external observations

Olympic venue hourly observations, venue names, coordinates and provider IDs are restricted. They are not included in this repository and are not licensed under either the MIT License or CC BY 4.0. The public repository contains only a synthetic interface, non-identifying design documentation and permitted aggregate summaries; it cannot execute the restricted external endpoint without separately authorized inputs.

No `restricted/` directory or restricted data file is included. Station-hour and venue-hour prediction tables are also excluded.

## Other excluded research artifacts

Model files, production models, station-hour predictions, venue-hour predictions, row-level OOF results, row-level WCT results, bootstrap replicate tables, NetCDF files and complete regional grids are not included in this repository. No license is granted here to artifacts that are absent from the repository or to third-party material incorporated upstream.
