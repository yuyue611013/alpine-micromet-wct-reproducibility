# Code availability

This author-review candidate includes:

- pure scientific contracts and synthetic tests;
- an aggregate-only public result reproduction workflow;
- an opt-in full component OOF and downstream scientific-analysis pipeline for authorized prepared inputs;
- a schema-only external interface;
- public figure renderers;
- security, reference-output and clean-room verification tools.

The opt-in route covers overall/monthly/representativeness/station metrics, paired component bootstrap, primary WCT and bootstrap, piecewise sensitivity, and all-station plus mismatch-excluded direct-WCT comparisons. Its station-level and row-level products are confined to the user's local output root.

It does not contain the historical code tree, real external-data runner, production external runner, full-grid generators or direct-WCT training code.
