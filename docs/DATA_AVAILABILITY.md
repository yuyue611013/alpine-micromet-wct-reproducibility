# Data availability

## Included

Only public-safe aggregate material is included:

- overall component metrics;
- monthly component metrics;
- elevation/representativeness group metrics;
- station-cluster bootstrap summaries (not replicate rows);
- primary and piecewise WCT summaries;
- aggregate direct-WCT comparison;
- aggregate cross-year external metrics;
- manuscript table source;
- anonymous aggregate figure source data.

The author-created public-safe aggregate paths expressly listed in `DATA_LICENSE.md` are offered under CC BY 4.0. That license does not extend to source code, third-party data, restricted records or artifacts not included in this repository.

## Not included

The repository contains no raw Meteostat observations, ERA5-Land files, terrain grids, station identities, station coordinates, station-hour predictions, OOF rows, WCT rows, bootstrap replicate tables, models, complete 1-km outputs or permission-controlled external observations.

ERA5-Land and Meteostat inputs must be obtained independently under their current terms. Full-pipeline users must prepare the documented input contract and verify redistribution rights. The real external endpoint requires explicit permission from the data provider and is not publicly reproducible from this repository.
