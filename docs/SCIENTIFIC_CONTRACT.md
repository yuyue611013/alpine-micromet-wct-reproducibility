# Scientific contract

This repository is locked to `WCE_SCIENTIFIC_CORRECTION_V1`.

## Environmental predictors

- ERA5-Land accumulated hourly surface solar radiation in J m-2 is divided by 3600 to W m-2 before current, lag, rolling, difference, change or interaction features are generated.
- Unknown SSRD units are a stopping error.
- Temperature and dew point use the same scalar feature order. Ralong and Rcross use the same rotated-wind feature order.

## Cross-validation and fitting

- Five deterministic station groups form the outer folds.
- Every station appears in exactly one outer prediction cohort.
- The outer fold is inaccessible to training, early stopping and iteration selection.
- Each of the other four original folds is used once as an inner station-grouped validation set.
- Sort the four best iterations and select `floor((b2 + b3) / 2 + 0.5)`.
- Refit on the complete eligible outer-training cohort with fixed selected rounds, no validation data and no early stopping.
- Seventeen elevation-mismatch stations are excluded from T/Td training but retained in their assigned outer prediction cohort. Wind does not apply this exclusion.
- Training seed: 20260127.

## OOF prediction

- Models run on the four actual 1-km grid cells that surround each station, not on a nearest-sampled station feature vector.
- Cell outputs are interpolated with the canonical bilinear weights.
- No complete Alpine grid is generated by this workflow.
- Td keeps both unconstrained and constrained values. The constraint is applied after a one-to-one merge on station, UTC hour and fold: `Td_constrained = min(Td_unconstrained, T_corrected)`.
- Ralong/Rcross residuals are rotated to U/V residuals with the locked DEF1 convention, added to background U/V, and wind speed is the vector magnitude.

## Metrics and WCT

- Component evaluation uses strict station-held-out OOF rows.
- The paired station-cluster bootstrap uses 2,000 replicates, seed 20260825 and the same cluster draws for baseline and corrected estimates.
- Primary WCT uses rows with observed temperature at or below 0 °C, the standard Celsius formula, wind converted from m s-1 to km h-1, and 0.1 m s-1 only as a numerical floor. No wind-height adjustment is applied.
- Piecewise low-wind WCT is supplementary sensitivity and never replaces the primary endpoint.
- Existing direct-WCT OOF predictions are frozen input; this repository never retrains them. Component and direct pathways retain distinct background representations.

## External result

The public aggregate external result is a calendar-aligned cross-year operational stress test, not same-year independent validation. The executable real-data endpoint is excluded and requires separate data permission.
